# 达人沟通台

一个本地运行的 WhatsApp 达人沟通助手。每位达人拥有独立档案、聊天记录、合作条款和 AI 上下文，避免把不同达人的条件混在一起。

## 日常使用

1. 双击桌面的 `达人沟通台` 图标；黑色命令窗口不会再闪现。
2. 等待“达人沟通台”独立窗口自动弹出。
3. 点击“导入聊天”：可以给当前达人粘贴记录，也可以一次选择多个 WhatsApp 导出的 TXT 或 ZIP。
4. 在右侧用中文写想表达的意思，点击“生成英文回复”。
5. 查看中文回译和风险提醒，确认后复制英文到 WhatsApp。

不需要预先打开 LM Studio。启动程序会自动启动本机接口、载入 `gemma-4-12b` 并关闭该模型的慢速思考模式。

## 模型模式

- **本机 LM Studio（默认）**：聊天内容不离开电脑。短回复通常约 2 秒；复杂条款回复约 10 至 20 秒；很长的首次分析可能约 1 分钟。
- **Gemini API（可选）**：速度和长记录能力更强，需要在“模型设置”中填写自己的 API Key。免费额度的数据可能被服务商用于改进产品，因此程序会先隐藏邮箱、电话和详细地址。
- **Groq API（推荐云端模式）**：使用 `qwen/qwen3.6-27b`，中文和英文商务沟通能力较好，免费额度充足，普通推理请求默认不保留。
- **OpenRouter 免费模型（备用）**：无需固定某一个模型，但每天免费请求较少，模型和服务商可能变化。
- Groq 使用自动接力：`Qwen 3.6 27B` 不可用时尝试 `GPT-OSS 120B`，仍不可用才改用本机 `Gemma 4 12B`。回复结果会显示实际使用的模型。

导入、保存、搜索和消息去重全部在本机完成，不调用任何 AI 接口，也没有次数限制。只有“生成英文回复”和“分析近况”会调用当前选择的模型。

## WhatsApp 记录迁移与同步

### 首次批量导入

1. 在手机 WhatsApp 中逐个打开重要聊天并选择“导出聊天”，无需包含媒体。
2. 把导出的 TXT 或 ZIP 放到电脑上。
3. 在达人沟通台点击“导入聊天” -> “批量导入文件”，一次选择多个文件。
4. 程序会自动识别联系人、建立或匹配达人档案，并显示新增、重复和跳过数量。

同一个文件可以重复导入。旧消息会自动跳过，只补进新消息，因此后续可把重新导出的聊天当作增量同步。

### Chrome 同步助手

安装文件在 `whatsapp-sync-extension` 文件夹。Chrome 因安全限制需要本人完成一次安装：

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择下载后的 `<项目目录>\whatsapp-sync-extension` 文件夹。
4. 以后打开 WhatsApp 网页和一位达人聊天，点击右下角“同步当前”或“同步全部”。

“同步全部”会依次打开当前聊天列表中的对话，因此未读聊天可能变成已读；开始前会再次确认，并且运行中可以停止。同步助手只读取每个聊天已经加载出来的文字消息。需要更早的记录时，先在 WhatsApp 聊天中向上滚动，等待旧消息显示，再点击“同步当前”。它不会发送消息，也不保存 WhatsApp 登录信息。

从扩展 1.2.0 起，“同步全部”需要 Chrome 的 `debugger` 权限来产生 WhatsApp 接受的真实点击。该权限只在用户点击“同步全部”后连接当前 WhatsApp 标签，并在完成、停止或出错后立即断开。扩展代码不读取网络请求，也不控制其他标签，但 Chrome 显示高权限警告属于正常现象。

## 数据位置

- 达人和聊天：`data/creator_hub.db`
- 运行记录：`logs/`
- 停止程序：双击 `停止达人沟通台.cmd`

程序不会自动发送 WhatsApp 消息。所有英文回复都由你确认后手动发送。

## 隐私与发布

`data/`、`logs/`、数据库、浏览器资料和 API Key 都属于本机私有数据，已通过 `.gitignore` 排除，不应上传到 GitHub。公开仓库只包含程序代码、扩展代码、测试和使用说明。
